How to use this app

One-time setup: On Settings, paste the school's Anthropic API key and save. The key stays in this browser only.

Each semester:

  1. Drop the semester's syllabi on the Upload tab and correct any guessed course or semester labels.
  2. Click Run Extraction and wait. Each syllabus takes roughly 20 to 60 seconds.
  3. On Results, spot-check a sample of rows against the original syllabi. Yellow cells first. Check off each reviewed row.
  4. Click Save Database File and put the file in the shared folder. This file is the repository. Load it back anytime, on any computer.
  5. Export CSV whenever you want to analyze in Excel, Airtable, or Power BI.

Multi-section syllabi: A syllabus covering several sections becomes one row per section. Rows from the same file share a Source value.

Durable skills: Tagged against the eleven Essential Skills defined by the David Eccles School of Business, drawing on definitions from AACSB, NACE, USHE, and U of U frameworks. Each tag includes the evidence the AI found. Treat skills as inferences to verify, not facts.

Adding fields later: Add the field on the Fields tab, then re-run older syllabi if you need the new field filled in historically.
