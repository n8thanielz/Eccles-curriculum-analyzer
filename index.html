How to use this app

One-time setup: On Settings, paste the school's Anthropic API key and save. The key stays in this browser only.

Each semester:

  1. Drop the semester's syllabi on the Upload tab and correct any guessed course or semester labels.
  2. Click Run Extraction and wait. Each syllabus takes roughly 20 to 60 seconds.
  3. On Results, spot-check a sample of rows against the original syllabi. Focus on yellow cells — these were flagged by the AI as uncertain or returned "not stated".
  4. Click Save Database File and put the file in the shared folder. This file is the repository. Load it back anytime, on any computer.
  5. Export CSV whenever you want to analyze in Excel, Airtable, or Power BI.

Multi-section syllabi: A syllabus covering several sections becomes one row per section. Rows from the same file share a Source value.

Skills tagging: Every syllabus is tagged against two frameworks simultaneously — the eleven Essential Skills defined by the David Eccles School of Business (synthesized from AACSB, NACE, USHE, and U of U definitions), and the eight NACE career readiness competencies. Each skill is assigned an intensity: Primary (core to the course with multiple graded assessments), Secondary (at least one graded component), or Incidental (present but not a graded focus). Use the Skills Matrix tab to view either framework. Treat all skill tags as AI inferences to verify, not established facts.

Bloom's Taxonomy: The AI identifies which of the six cognitive levels (Remember → Create) are present in each course's learning outcomes and assessments. View the distribution on the Dashboard tab. This helps the school assess the cognitive depth of its curriculum.

Dashboard & Coverage Analysis: The Dashboard shows aggregate stats, a skill coverage heatmap by department, and a Bloom's distribution chart. The Coverage Analysis tab highlights departments and skills where coverage falls below a configurable threshold — use it to identify curriculum gaps.

Adding fields later: Add the field on the Fields tab, then re-run older syllabi if you need the new field filled in historically.
