Eccles Curriculum Analyzer — Timesheet Generator

Click the button to download a formatted Excel timesheet. Open the file and type hours into the yellow Hours column — the Running Total and subtotals update automatically.

  • Re-generate and re-open the file each time you need a fresh copy with new rows added.
  • New commit sessions are added to the DEV_SESSIONS array in this file by Claude as development continues.

Uses xlsx-js-style (MIT). Requires an internet connection to load the library on first use.
